Ideal way to build it (simple and realistic)
Build it like this:

Data collector (Python)

Pull football fixtures + odds + results from an API
Save into PostgreSQL
Prediction engine (Python)

Apply your draw criteria (rules first, ML later)
Score matches
Keep top 3–10 picks per day
Backend API (FastAPI)

Endpoints like:
/matches?date=YYYY-MM-DD
/draw-picks?date=YYYY-MM-DD
/draw-picks/range?from=...&to=... (for -3/+3 days)
Frontend (Next.js + Tailwind)

Date selector
7-day scrolling window (3 days before + selected day + 3 days after)
Cards showing confidence + why match passed criteria
Deployment

Backend on Render/Railway
DB on Supabase/Neon/Postgres
Frontend on Vercel

Example criteria (you can tune later):

Low goal difference trend
